bodit app — 매입내역 자동완성 화면 흐름

증빙을 올리면 항목을 자동으로 채우고, 확인 후 제출하면 Google Sheets · Google Drive · Slack 세 곳에 동시에 올라간다. 승인 단계는 없다 — 회계 담당자는 Sheets 를 읽기만 한다.
동작 흐름 공유용 시안 · 디자인 확정본 아님 · iPhone 17 Pro (402×874pt) · 2026-09-14
1회사 Google 계정으로 로그인 (@bodit.co 만)
2홈 — 촬영 / 파일 선택, 전송 대기 큐, Sheets·Drive 바로가기
3촬영 — 프레임 가이드
4OCR — 이미지에서 항목을 추출하고 과거 이력을 조회
5검토 폼 ① — 프리필된 값. 확신이 낮은 항목만 노란색
6검토 폼 ② — 비목·분류코드는 과거 이력으로 추천 + 근거 표시
7비목 선택 — 추천·최근순으로 정렬된 검색 목록
8검토 폼 ③ — 금액. 부가세는 자동 계산하지 않고 물어본다
9제출 — 세 곳에 동시에 올라간다
10완료 — Slack 에 올라간 모습까지 확인
11내 제출 목록 — 부분 실패(Slack 만 실패)가 여기서 보인다
12오프라인 — 로컬에 쌓아두고 연결되면 자동 전송 (해외 출장)
이 시안이 보여주려는 것
· 15개 필드를 처음부터 채우지 않는다 — OCR 로 읽고(③④), 확신 낮은 것만 노란색으로 묻는다(⑤)
· 비목·분류코드는 영수증에 없다 — 과거에 같은 업체를 어떻게 처리했는지 보고 제안한다(⑥⑦)
· 부가세는 자동 계산하지 않는다 — 면세가 있어서 물어본다(⑧)
· 목적지가 3곳이라 하나만 실패할 수 있다. 실패한 곳만 다시 보낸다(⑨⑪)
· 오프라인(해외 출장)에서는 찍어두고 연결되면 자동 전송한다(⑫)
